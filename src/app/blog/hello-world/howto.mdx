## How to write a new post

Create a folder under `src/app/blog/` with a `page.mdx` inside:

```
src/app/blog/my-new-post/page.mdx
```

Start it with the same few lines this file has — the `PostHeader` import and a
`post` object with a title, date, and tags. The blog index finds and lists
posts automatically, sorted by date. Then just write markdown below it:

- Run `npm run dev` and the post hot-reloads as you type
- Links, `inline code`, images, and code blocks all work out of the box

```python
def hello():
    print("world")  # syntax shown in a styled block
```

> Blockquotes look like this.

And because it's MDX, you can import and render React components right inside
a post whenever plain markdown isn't enough — interactive demos, plots,
whatever you need.
